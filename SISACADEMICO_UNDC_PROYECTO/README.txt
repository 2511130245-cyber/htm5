
SISACADEMICO UNDC - PROTOTIPO TAILWIND

COMO ABRIR:
1. Extrae esta carpeta.
2. En VS Code: Archivo > Abrir carpeta.
3. Selecciona "SISACADEMICO_UNDC_PROYECTO".
4. Abre index.html.
5. Si tienes Live Server: clic derecho sobre index.html > Open with Live Server.

IMPORTANTE:
- Es un prototipo visual y funcional de navegación.
- Tailwind se carga por CDN, por lo que se necesita Internet para cargar los estilos.
- No está conectado a una base de datos ni al sistema real de la UNDC.
- Puedes modificar textos, colores, cursos y datos directamente en los HTML.
